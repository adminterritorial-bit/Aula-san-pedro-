# Aula de Formación · Demo

Demo autónoma y editable de una plataforma de formación corporativa.

- Sin base de datos ni servicios externos.
- Persistencia de demostración únicamente en localStorage.
- Sin logos ni activos corporativos del proyecto original.
- Incluye catálogo, progreso secuencial, evaluación final, certificados y panel administrativo.
- Despliegue preparado con GitHub Actions + GitHub Pages.

Esta versión es exclusivamente demostrativa y no debe utilizarse como sistema de autenticación de producción.
